# PET Substrate Binding & Active Site Distances

This directory contains PyMOL session files (`.pse`) dedicated to the spatial and geometric analysis of the active site relative to the PET substrate.

### Contents
- **Catalytic Triad Alignment:** Distance measurements (in Ångströms) for catalytic residues (Ser-His-Asp).
- **Substrate Binding Pocket:** Geometric positioning and steric fit relative to PET substrate / ligand models.
